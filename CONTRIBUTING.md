# Как помочь Zapret-Next

Спасибо за желание улучшить проект. Хороший Issue экономит время на уточнения,
а хороший Pull Request решает одну понятную задачу и оставляет проверяемый след.

## Перед созданием Issue

1. Проверьте, что используете последнюю сборку.
2. Найдите похожие открытые и закрытые Issues.
3. Попробуйте другую стратегию и укажите результат.
4. Если участвуют VPN, v2rayNG или другие root-сетевые приложения, повторите
   проверку с ними и без них.
5. Экспортируйте журнал из WebUI и удалите из него приватные домены, IP-адреса
   и другие чувствительные данные.

Для ошибки используйте шаблон bug report. Для новой возможности — feature
request. Вопрос «какая стратегия сейчас работает у провайдера» лучше задавать
авторам базы стратегий Flowseal, потому что Zapret-Next отвечает за Android-модуль.

## Что должно быть в bug report

- версия Zapret-Next;
- модель устройства, версия Android, ядро и архитектура;
- KernelSU/Magisk и его версия;
- выбранные стратегия, режим и firewall backend;
- точные шаги воспроизведения;
- ожидаемое и фактическое поведение;
- сведения о VPN, прокси и других сетевых root-модулях;
- экспортированный журнал.

Скриншот полезен для WebUI, но не заменяет текст ошибки и журнал.

## Pull Request

Перед изменениями создайте Issue для крупных или спорных функций. Небольшие
исправления документации и очевидные bugfix можно отправлять сразу.

Требования к коду:

- shell-код должен работать в Android `/system/bin/sh` и BusyBox ash;
- не добавляйте зависимости, если хватает платформенных команд;
- сохраняйте исключения VPN/TUN и совместимость с v2rayNG;
- не включайте в коммит собранный ZIP, временные файлы и личные логи;
- добавляйте минимальный тест для новой ветки или исправленной ошибки;
- один PR — одна задача.

Проверка перед отправкой:

```sh
./tests/test_all.sh
git diff --check
```

Если менялись сборка, установщик или содержимое модуля, дополнительно выполните:

```sh
./build.sh
unzip -t Zapret-Next.zip
```

В описании PR объясните проблему, решение, способ проверки и возможные риски.
Отправляя вклад, вы подтверждаете, что имеете право предоставить этот код и
соглашаетесь на его распространение вместе с проектом.
